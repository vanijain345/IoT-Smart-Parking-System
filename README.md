# IoT Smart Parking System

## Overview
An IoT-based smart parking system that allows users to pre-book parking slots and check real-time parking slot availability.

## Objective
The main objective is to make parking easier by providing information about available slots and allowing users to reserve a slot in advance.

## Key Features
- Real-time parking slot availability
- Parking slot pre-booking
- IoT-based monitoring
- Automated slot status detection

## Technologies Used
- IoT
- Microcontroller
- Sensors
- C++ Programming 
- Arduino/ESP32

## Working
The system uses sensors to detect the availability of parking slots. The collected information is processed by the microcontroller and the parking status is updated so that users can check available slots and pre-book a slot.
